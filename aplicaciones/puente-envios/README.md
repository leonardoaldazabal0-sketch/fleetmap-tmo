# Puente de envios TMO

Fuentes conservadas de `tools/vm-bridge`. Los parametros de despliegue siguen apuntando
a `C:\ProgramacionBackup` y al NAS configurado en los scripts.

No ejecutar estos scripts durante una verificacion de carpetas: reciben paquetes y
pueden registrar o copiar programaciones. Esta migracion no los instala en otra VM.
La futura integracion debe exigir una aprobacion registrada antes de permitir el envio.
